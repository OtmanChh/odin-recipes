# About
This is a basic recipe website built with HTML alone, for now, as part of The Odin Project foundations curriculum.
This website features a collection of traditional Moroccan recipes including: couscous, harira, bisarra, rfisa, bastilla and more.


# Skills Demonstrated
In this project I practiced:
- HTML structure and boilerplate
- Using Elements and tags
- Working with text, links and images
- Using ordered and unordered lists
- Linking between multiple pages
- Organizing files and directories
